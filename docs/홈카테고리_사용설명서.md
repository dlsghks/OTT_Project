# 홈 카테고리 버튼 · 스페셜 페이지 사용설명서

홈 메인 히어로 아래 **카테고리 버튼(16개)** 과, 버튼을 눌렀을 때 열리는 **스페셜 페이지 · 이벤트 페이지 · 뉴스 화면**의 구조와, 무엇을 바꾸려면 어느 파일을 고치면 되는지 정리한 문서입니다.

- 기준: 2026-11-05 웨이브(wavve.com) 홈 카테고리 버튼과 각 스페셜 페이지 구성
- 데이터: 웨이브 화면을 보고 옮긴 정적 데이터(`data/specialPages.js` 등) + TMDB API(`VITE_TMDB_API_KEY`) + 유튜브 API(`VITE_YOUTUBE_API_KEY`)
- 디자인: 기존 카테고리 페이지(`Category.scss`) · 상세 페이지 영상 카드(`TotalSubDetail.scss`) 스타일을 그대로 사용

## 3. 화면 구성

### hero 구성 (웨이브 special 페이지 `.w-special-title` 기준, 1920px 화면 기준 수치)
| 형태 | 사용 페이지 | 배경 | 로고 · 글자 |
|---|---|---|---|
| 기본형 | 골프 · 뉴스를 뺀 모든 페이지 | `{이름}_hero.jpg` 1920×1080, 화면 너비 16:9로 깔리고 아래로 흐려짐 | 높이 540px 영역 가운데, 로고 380×132 → 18px 아래 설명 |
| 낮은형 `short` | 골프 · 뉴스 | `{이름}_hero.jpg` 1920×380 | 왼쪽 위(위 100px · 왼쪽 콘텐츠 여백) 로고 높이 60px, 설명 없음, 바로 아래 필터 탭 |

- 설명 글자: Noto Sans KR Regular 24px (1920px 이상 고정, 그보다 좁으면 1.25vw로 줄어듦 · 최소 16px), 줄 간격 1.45, 데이터의 `
`에서 줄바꿈 (웨이브와 같은 위치)
- 글꼴은 `index.html`의 Google Fonts 링크(Noto Sans KR 400)로 불러옵니다.
- 1920px 미만에서 높이 · 로고 · 여백은 화면 비율(vw)로 줄어들고, 1920px 이상은 기준 값으로 고정됩니다.
- 이미지: `public/images/special-hero/` (`{이름}_hero.jpg` 배경 · `{이름}_logo.png` 로고)
  - 데이터는 `specialPages.js`의 `hero: hero('이름', { short, tag, logo })`
  - `tag`: 로고 위 작은 태그 (옆자리, 프란체스카 = `woriginal.png`)
  - 예외: 영화+ = `movieplus_*`, 오직 웨이브에서 = `wonly_hero.jpg` + `wonly_.png`

### 스페셜 페이지 공통 (`SpecialPage.jsx`)
1. 상단 hero(`components/special/SpecialHero.jsx` + 공통 스타일 `styles/components/SpecialHero.scss`): 배경 이미지 + 로고 + 소개 문구 (아래 'hero 구성' 참고)
2. 필터 버튼(영화+ · 뉴스 · 골프만): `CategoryPage.jsx`와 같은 `.category-filter` 버튼
3. 섹션 목록(`components/wavve/SectionRenderer.jsx`): 섹션 `type`에 맞는 컴포넌트로 그림
4. 섹션 간격: **80px** (스페셜 페이지에서만 — 기존 카테고리 페이지는 그대로)

### 섹션 타입 (`specialPages.js`의 `sections[].type`)

| type | 모양 | 컴포넌트 |
|---|---|---|
| `poster` | 세로 포스터 가로 슬라이드 | `PosterRow` → `CategorySlider` → `ContentCard` (기존) |
| `rank` | 세로 포스터 + TOP 순위 숫자 | `RankRow` (기존) |

### TMDB 상세 연결 (`services/tmdbFind.js`)
1. 제목 정리: `[극장판]` · `(2026)` · `(자막)` 등 제거, `(연도)`는 영화 검색 연도로 사용
2. 검색: `kind=movie`는 `/search/movie`, `kind=multi`는 `/search/multi` (영화+ · 독점 영화 · CJ ENM 영화 섹션은 `movie`)
3. 정확히 같은 제목 우선, 같은 제목이 없으면 시즌·회차 표기를 뗀 검색어로 다시 검색 (예: `1박2일 시즌4` → `1박2일`, `짱구는 못말려25` → `짱구는 못말려`)
4. 상세 페이지 선택 (시리즈는 TMDB 장르 · 제작 국가 기준)

| TMDB 결과 | 상세 페이지 |
|---|---|
| 영화 | `/moviedetail/:id` |
| 애니메이션(16) | `/animationdetail/:id` |
| 다큐(99) · 뉴스(10763) | `/currentaffairsdetail/:id` |
| 리얼리티(10764) · 토크(10767) · 드라마 장르 없는 코미디(35) | `/entertainmentdetail/:id` |
| 해외 제작 시리즈 | `/globaldetail/:id` |
| 그 외 국내 시리즈 | `/dramadetail/:id` |

- `/open`은 상세 페이지로 `replace` 이동하므로, 상세에서 뒤로 가기를 누르면 스페셜 페이지로 돌아옵니다.
- TMDB에 없는 작품은 "'제목' 작품 정보를 찾을 수 없습니다."가 나옵니다.

### #시사토크 (`TalkRow.jsx`)
작품마다 ① TMDB 상세 → ② 없으면 유튜브 검색(영상 제목 · 채널명에 프로그램 이름이 들어 있을 때만 인정, `/news/clip/youtube?v=영상id&title=…` 재생) → ③ 둘 다 없으면 카드를 빼고, 빠진 개수만큼 메인 메뉴 시사교양(`categoryData.js`의 `currentaffairs`) 콘텐츠로 채웁니다.

## 7. 자주 하는 수정

### 홈 버튼 추가 · 순서 바꾸기
1. 버튼 이미지를 `public/images/category-buttons/이름.png`에 넣습니다 (400×200).
2. `homeData.js`의 `categories` 배열에 `{ label, path, image: categoryImage('이름') }`을 원하는 순서에 넣습니다.
3. 새 스페셜 페이지면 `specialPages.js`에 같은 `slug` 키로 페이지를 추가합니다 (주소 `/special/slug`).

### 스페셜 페이지 · 섹션 추가
```js
// src/data/specialPages.js
summer: {
  title: '여름방학',                       // 헤더 제목
  description: '웨이브 히어로 문구',        // 헤더 소개
  hero: hero('summer'),                    // 배경 summer_hero.jpg + 로고 summer_logo.png
  sections: [
    { id: 'fate', type: 'poster', title: '섹션 제목', items: posters('summer-fate', [
      ['작품 제목', '202610/1790907520476584005.jpg', '새로운'],  // [제목, 웨이브 이미지 경로, 표시]
    ]) },
    { id: 'clips', type: 'video', title: '영상 줄', items: forProgram(videos('summer-clips', [
      ['회차 제목', '202610/1792491256110580775.jpg', '설명', '2026-11-03(화)', '무료', '01:20'],
    ]), '여름방학') },
  ],
},
```
- `posters(key, [...])`: 표시 = `'새로운'` · `'개별구매'`(배지), `'original'` · `'exclusive'`(W 마크)
- `videos(key, [...], size, link)`: `[제목, 이미지, 설명, 날짜, 배지, 재생시간]`, `link`를 주지 않으면 제목으로 TMDB 연결
- `key`가 `movie-`로 시작하거나 `-movie`로 끝나면 영화로만 검색, `golf-` · `news-`로 시작하거나 `kbs-news24`면 `/live`로 연결
- 이미지 경로: 웨이브 이미지 주소에서 `https://image.wavve.com/v1/thumbnails/480_720/` 뒤 부분만 적습니다. `202610/1790907520476584005.jpg`처럼 `연월/숫자id` 형태면 `meta/image/`가 자동으로 붙습니다(`wavveImage`).
- 섹션 `id`는 페이지 안에서 겹치지 않게 합니다.

### 필터 탭 바꾸기
페이지의 `filters`에 `{ id, label, sections }` · `{ id, label, items }` · `{ id, label, link }` 중 하나로 넣습니다 (3장 "필터 버튼 동작" 참고). 첫 번째는 `{ id: 'all', label: '○○ 전체' }`.

### 뉴스 클립 추가 · 변경
`src/data/newsClips.js`의 `raw.탭id` 배열에 `[제목, 이미지, 재생시간, 출처, 날짜]`를 넣습니다. 클립 주소는 `/news/clip/탭id-순번`으로 자동 생성되고, 메인의 탭 줄에는 앞 10개가 나옵니다.

### 뉴스 채널 · #뉴스 라이브 연결 바꾸기
`specialPages.js`의 `newsChannels` · `newsPrograms`에서 `channelId`를 바꿉니다. id는 `data/liveData.js`의 `channelId`(라이브 탭에서 채널을 눌렀을 때 주소의 `?channel=` 값)와 같아야 합니다.

### TMDB 상세가 엉뚱한 작품으로 열릴 때
제목만으로 찾기 때문에 같은 이름의 다른 작품이 열릴 수 있습니다. 해당 콘텐츠의 `link`를 상세 주소로 직접 지정하세요.
```js
// TMDB 작품 페이지 주소(themoviedb.org/tv/숫자)의 숫자를 상세 주소 뒤에 넣습니다
{ ...posters('kbs-drama', [['태양의 후예', '202403/1710909420079184401.jpg']])[0], link: '/dramadetail/TMDB숫자id' }
```
상세 페이지 종류 기준은 `tmdbFind.js`의 `getTvPath`에서 바꿉니다.

### 섹션 간격 · 디자인
- 섹션 간격 80px: `Special.scss`의 `.special-page .category-page__sections > .category-row`
- 영상 카드: `TotalSubDetail.scss`의 `.movie-videos__card`(상세 페이지와 공통) + `Special.scss`의 `.video-row__*`(배지 · 재생시간 · 순위)
- 필터 버튼: `Category.scss`의 `.category-filter__button`(기존 카테고리 페이지와 공통)
- 뉴스 그리드 열 수: `Special.scss`의 `.news-list__grid` (7 → 1440px 이하 5 → 1024px 이하 4 → 768px 이하 2)

### 유튜브 검색 결과 지우기
브라우저 개발자도구 → Application → Local Storage에서 `news-clip-youtube-cache`를 삭제하면 뉴스 클립 · 시사토크 영상을 다시 검색합니다.

## 8. 참고 · 한계

- 콘텐츠와 이미지는 2026-11-05 웨이브 기준 정적 데이터입니다. 웨이브 편성이 바뀌면 직접 갱신해야 하고, 포스터 · 썸네일은 웨이브 이미지 서버(`image.wavve.com`) 주소라 웨이브가 이미지를 바꾸면 깨질 수 있습니다.
- TMDB에 없는 작품(골프 대회, 일부 키즈 콘텐츠 등)은 상세 페이지 대신 "찾을 수 없습니다" 안내가 나옵니다. 골프 · 뉴스 클립은 이 때문에 `/live`나 뉴스 클립 재생으로 연결했습니다.
- 뉴스 클립 영상은 제목으로 찾은 유튜브 영상이라 웨이브 원본과 다를 수 있습니다. 유튜브 API는 하루 검색량이 정해져 있어 처음 보는 클립은 하루 약 100개까지 검색됩니다(한 번 찾은 결과는 브라우저에 저장).
- 출석체크 기록은 브라우저에만 저장되어 다른 기기 · 브라우저와 공유되지 않습니다.
- MMA 이벤트의 응모 · 응원 · 이용권 구매는 안내 화면만 있고 실제 응모 기능은 없습니다.
