# 상세 페이지 사용설명서

영화 · 예능 · 드라마 · 시사교양 · 애니 · 해외시리즈 상세 페이지의 구조와, 무엇을 바꾸려면 어느 파일을 고치면 되는지 정리한 문서입니다.

- 데이터: TMDB API (`.env`의 `VITE_TMDB_API_KEY` 필요)
- 디자인: `MovieDetail.jsx`(영화 상세)의 디자인을 시리즈 상세에서도 그대로 사용
- 로그인 상태: Firebase 로그인 (`useMovieStore`의 `user`)

---

## 1. 주소(라우트)

| 카테고리 | 상세 주소 | 페이지 파일 |
|---|---|---|
| 영화 | `/moviedetail/:movieId` | `src/pages/contents/MovieDetail.jsx` |
| 예능 | `/entertainmentdetail/:programId` | `src/pages/contents/EntertainmentDetail.jsx` |
| 드라마 | `/dramadetail/:programId` | `src/pages/contents/DramaDetail.jsx` |
| 시사교양 | `/currentaffairsdetail/:programId` | `src/pages/contents/CurrentaffairsDetail.jsx` |
| 애니 | `/animationdetail/:programId` | `src/pages/contents/AnimationDetail.jsx` |
| 해외시리즈 | `/globaldetail/:programId` | `src/pages/contents/GlobalDetail.jsx` |

`:programId` 자리에는 두 종류가 들어갈 수 있습니다.

- 카테고리 데이터 id (예: `ent-01`, `dra-01`): `categoryData.js`의 콘텐츠. `contentCatalog.js`에 `tmdbId`가 있으면 그 값을 쓰고, 없으면 제목(`tmdbTitle` → `title`)으로 TMDB를 검색합니다.
- TMDB id 숫자 (예: `94997`): 상세 페이지 안의 추천 카드처럼 TMDB에서 가져온 작품.

라우트 등록 위치: `src/routers/AppRouter.jsx`의 `{/* 콘텐츠 상세 */}` 아래.

## 2. 화면 구성

### 영화 (`MovieDetail.jsx`)
1. 히어로: 배경, 타이틀 로고, `연도 · 러닝타임 · 등급 · 장르`, 버튼, 줄거리, 출연
2. 관련영상 (유튜브 예고편, 누르면 팝업 재생)
3. 시리즈 → 비슷한 영화 → 새로 올라온 영화 → 요즘 인기 있는 {장르} → {배우} 팬이라면 무조건 PLAY! ×2 → {감독} 감독의 다른 영화

### 시리즈 (예능 · 드라마 · 시사교양 · 애니 · 해외시리즈, `TvDetail.jsx`)
1. 히어로: 배경, 타이틀 로고, `등급 · 장르`, 버튼(**시즌 선택** + 시청하기), 줄거리, 출연, 히어로 아래 가운데 **펼치기**
2. 펼치기를 누르면: 로고 · 버튼 위치와 배경 이미지 크기는 그대로 두고, 줄거리가 2줄 → 전체로 늘어나며 출연 아래로 상세 정보(개요 · 장르 · 감독 · 작가)가 내려오고 가운데 접기 버튼이 붙습니다. 그 높이만큼 아래 테마가 모두 밀립니다. (영화 상세도 동일)
3. 시즌별 회차: `{작품명} 시즌N (총 N화)`, 오른쪽 `첫화부터 · 최신화부터` 정렬
4. 비슷한 프로그램 → 방영 중인 {카테고리} → 믿고 보는 웨이브 에디터 추천작 → 요즘 인기있는 {카테고리} → {배우} 팬이라면 무조건 PLAY! ×2

### 버튼 동작 (공통)
| 상태 | 버튼 영역 | 관심(하트) |
|---|---|---|
| 로그인 전 | 파란 **로그인** 버튼만 (누르면 `LoginModal`) | 누르면 `LoginModal` |
| 로그인 후 | 영화: 자막 선택 + 시청하기 / 시리즈: 시즌 선택 + 시청하기 | 관심 표시 켜기/끄기 |

- **시청하기**(영화 · 시리즈 공통)를 누르면 예고편이 유튜브 팝업으로 재생됩니다. 영상 찾는 순서: ① TMDB 예고편(Trailer > Teaser > 아무 유튜브 영상) → ② 없으면 유튜브 검색 (`{제목} 예고편`).
- 영상 플레이어(`components/common/YoutubePlayerModal.jsx`)는 **전체화면**으로 열립니다. 상단 왼쪽 뒤로가기(‹) 버튼이나 ESC로 닫고, 오른쪽에 날짜와 "YouTube에서 보기" 링크가 있습니다. 레트로브 메인 · 상세의 영상 카드도 같은 플레이어를 씁니다.
- 시리즈 회차 카드는 로그인 전에 누르면 `LoginModal`이 뜨고, 로그인 후에 누르면 영화의 관련영상처럼 유튜브 영상 플레이어가 뜹니다. 영상 찾는 순서: ① `data/episodeYoutube.js` 직접 지정 → ② TMDB 회차 영상 → ③ 유튜브 검색. 영상을 찾아도 회차 썸네일은 TMDB 이미지 그대로입니다.
- 로그인 전에는 시즌 선택이 숨겨지고, 회차 목록은 기본 시즌(아래 참고)을 보여줍니다.
- 기본 시즌: `contentCatalog.js`의 `tmdbSeason`이 있으면 그 시즌, 없으면 가장 최근 시즌.

```
│  ├─ EpisodeRow.jsx             시즌별 회차 (시리즈)
│  ├─ VideoSlider.jsx            16:9 영상 카드 가로 슬라이드 (관련영상 · 회차 공통)

│  └─ TvDetail.jsx               시리즈 상세 공통 본문 (5개 카테고리가 함께 사용)

├─ components/common/YoutubePlayerModal.jsx  유튜브 영상 전체화면 플레이어 (상세 · 레트로브 공통)
├─ hooks/useVideoPlayer.js       유튜브 영상 팝업 상태 (관련영상 · 예고편 · 회차 영상)
├─ services/youtubeSearch.js     유튜브 검색 + 브라우저 저장 (예고편 · 회차 영상 공통)
├─ data/episodeYoutube.js        회차 영상 유튜브 검색 설정
├─ services/tmdbDetail.js        TMDB 요청 · 카드 변환 · 로고 · 등급 · 날짜 도우미
├─ store/
│  ├─ useMovieStore.js           영화 TMDB 데이터 + 로그인 상태(user)
│  └─ useTvStore.js              시리즈 TMDB 데이터 (상세 · 시즌 회차 · 테마 섹션)
└─ styles/pages/TotalSubDetail.scss 상세 페이지 공통 스타일 (영화 · 시리즈)
```

## 5. 자주 하는 수정

### 시리즈 테마 섹션 순서 · 제목 바꾸기
`src/components/detail/TvDetail.jsx` 맨 아래 `<DetailSections sections={...} />`의 배열 순서를 바꿉니다.
섹션 제목은 `src/store/useTvStore.js`의 `onFetchTvSections` 안 `sections` 객체에서 바꿉니다.

### 카테고리별 "방영 중 · 요즘 인기" 기준 바꾸기
각 페이지 파일의 `config.discover`를 고칩니다. TMDB `/discover/tv` 조건이 그대로 들어갑니다.

```js
// src/pages/contents/EntertainmentDetail.jsx
const config = {
  category: 'entertainment',      // categoryData.js 의 categoryPages 키
  name: '예능',                   // 섹션 제목에 들어가는 이름
  basePath: '/entertainmentdetail', // 추천 카드를 눌렀을 때 이동할 주소
  backLink: '/entertainment',     // 찾을 수 없을 때 돌아갈 페이지
  discover: { with_genres: '10764|10767', with_origin_country: 'KR' },
  personExcludeGenres: [],        // 배우 출연작에서 뺄 장르 id
};
```

주요 TMDB TV 장르 id: 드라마 18, 코미디 35, 애니메이션 16, 다큐멘터리 99, 뉴스 10763, 리얼리티 10764, 토크 10767

### "믿고 보는 웨이브 에디터 추천작" 바꾸기
TMDB가 아니라 같은 카테고리의 `categoryData.js` 콘텐츠를 씁니다(배지 · 오리지널 콘텐츠 먼저, 최대 20개).
기준은 `TvDetail.jsx`의 `editorPicks`에서 바꿉니다.

### 펼치기 정보 행 바꾸기
- 행 종류(개요 · 장르 · 감독 · 작가)는 `services/tmdbDetail.js`의 `getDetailInfo`에서 바꿉니다. 영화 · 시리즈에 함께 적용됩니다.
- 들어가는 값은 영화는 `MovieDetail.jsx`, 시리즈는 `TvDetail.jsx`의 `getInfo`에서 바꿉니다.
  - 영화 개요: 제작사, 개봉 연도 / 시리즈 개요: 방송사, 방영 기간
  - 감독: `Director` / 작가: `WRITER_JOBS` (Writer · Screenplay · Story · Novel)
- `value`가 비어 있으면 그 행은 숨겨집니다.

### 펼치기 · 접기 버튼 바꾸기
- 글자 · 아이콘: `DetailHero.jsx` (아이콘은 lucide-react `ChevronDown` · `ChevronUp`, 이미지 아님)
- 디자인: `TotalSubDetail.scss`의 `.detail-toggle` (타이포그래피 버튼M(Default))
- 위치: 펼치기는 `.movie-hero__toggle`(히어로 아래 가운데), 접기는 `.detail-info__fold`(상세 정보 아래 가운데)
- 펼친 상태: `.movie-hero.is-expanded` — 펼치기 직전 히어로 높이(`--hero-height`)와 내용 시작 위치(`--content-top`)를 `DetailHero.jsx`에서 계산해 고정하고, 히어로가 아래로만 늘어납니다.
- 상세 정보 행 디자인: `.detail-info__row` (`라벨:` + 값, 출연과 같은 왼쪽 정렬)

### 히어로 · 카드 디자인 바꾸기
`src/styles/pages/TotalSubDetail.scss` 한 곳만 고치면 영화와 시리즈에 함께 적용됩니다.
(클래스 이름은 기존 영화 상세의 `movie-hero`, `movie-videos` 등을 그대로 사용합니다.)

### 새 카테고리 상세 추가하기
1. `src/pages/contents/`에 기존 `*Detail.jsx` 하나를 복사해 `config`만 바꿉니다.

### 회차 영상(유튜브 검색) 바꾸기
`src/data/episodeYoutube.js`에서 고칩니다.

- 검색어 단어 바꾸기: `episodeSearchConfig`의 `unit`(회/화) · `keyword`(예: 하이라이트)
- 검색어 모양 바꾸기: `buildEpisodeQuery` (예: `놀면 뭐하니? 1회 하이라이트`, 시즌이 2개 이상이면 `모범택시 시즌3 1화 하이라이트`)
- 엉뚱한 영상이 나올 때: `episodeVideoOverrides`에 `'TMDB id-시즌-회차': '유튜브 videoId'`를 넣으면 검색보다 먼저 사용합니다.
- 이미 저장된 검색 결과를 지우려면 브라우저 개발자도구 → Application → Local Storage에서 `detail-episode-youtube-cache`를 삭제합니다.

## 6. 참고 · 한계

- TMDB에 정보가 없는 작품은 "프로그램 정보를 찾을 수 없습니다."가 표시됩니다. 검색이 다른 작품으로 연결되면 `contentCatalog.js`에 `tmdbId`를 넣어 고정하세요.
- 장르 이름이 TMDB에 한국어 번역이 없으면 영어로 나옵니다 (예: `Reality`).
- 회차가 많은 작품(예: 런닝맨 800화 이상)은 한 시즌의 모든 회차를 가로 목록으로 보여줍니다.
- 시청하기는 본편이 아니라 예고편(관련 영상)을 재생합니다.
- 유튜브 검색은 `.env`의 `VITE_YOUTUBE_API_KEY`가 필요하고 하루 검색량이 정해져 있습니다. 검색량을 넘으면 팝업에 "재생할 수 있는 영상을 찾지 못했어요."와 유튜브 검색 링크가 나오고, 결과를 저장하지 않으므로 다음 날 다시 검색합니다.
